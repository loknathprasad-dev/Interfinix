# Interfinix - Interview Preparation Platform

Interfinix is a web-based platform designed to help students and job seekers prepare for technical and HR interviews using AI-driven mock tests.

## 🚀 Features
- **Job Field Selection**: Choose from Web Dev, DSA, AI/ML, etc.
- **Mock Interviews**: Interactive quiz sessions.
- **Dashboard**: Track your progress and scores.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Gradients & Responsive Design)
- **JavaScript** (Vanilla)

## 📂 How to run
1. Clone this repository.
2. Open `index.html` in any modern web browser.
